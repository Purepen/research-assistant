Design proposal · 02

One design system,
every screen

The product currently ships four incompatible visual languages. This proposal replaces them with a single editorial system — scholarly serif display, disciplined green, paper-calm surfaces — applied to every page, keeping the white-and-green identity the product already owns.

Foundations
Type · color · space · voice
Components
One library, both form factors
Six key screens
Landing · auth · dashboard · wizard · reader · Topic Lab
research-assistant · companion to the mobile redesign16 July 2026
Why

Four themes today → one system

02 / 10
Shipping today — simultaneously
1 · Landing
Custom CSS, dark hero, own button styles
2 · Core auth
Green split-panel, Sora/DM Sans, own CSS file
3 · Peripheral auth
Tailwind blue/purple gradients, lucide icons
4 · Dashboard
g-* classes + heavy inline style={{}} per element

Plus a fifth, fully dead system in components/ui/, ~150 lines of unreachable navy CSS, and ~90 hand-rolled icon functions duplicated across 9 files. Every new page rolls dice on which language it speaks.

The cost Inconsistency reads as unfinished — for a product asking students to trust it with graded work, visual coherence is credibility. And every duplicated style is a bug surface (the status-color typo that hid completed projects lived in exactly this duplication).
The proposed voice — "scholarly, calm, green"
Editorial identity
Research is a craft.
The interface should read like one.
  • 1Fraunces (a scholarly display serif, already sneaking into dashboard headings) becomes the deliberate voice for every display heading and document surface.
  • 2DM Sans carries all UI: labels, buttons, body, data. Sora retires to the wordmark only.
  • 3One green (#16a34a) for every action; #4ade80 only as accent on dark. Blue/purple exit entirely.
  • 4Dark forest (#0f1f0f) is structural, not decorative: hero, sidebar, CTA band — the three "moments", everything else stays paper-white.
  • 5Dot-grid + green glow is the single recurring texture, only ever on dark surfaces.

Space & shape
4px base grid · radii 10 (inputs) / 14 (cards) / 18 (modals) · borders 1px hairline, 1.5px on interactive · two shadows only: rest (0 1 3 · 7%) and raised (0 8 24 · 8%)
Type — two families, five sizes
Display — Fraunces 600
Page titles, hero, document headings · 30–56px
Wordmark — Sora 800 only
ResearchAI logotype, nothing else
Heading — DM Sans 700 · 16–20px
Card titles, section heads
Body — DM Sans 400/500 · 14–15px, 1.6 line-height
Label — DM Sans 700 · 10–11px caps, .12em tracking
Document — Georgia/Fraunces 15–16px · 1.75 — the generated specification always reads like a manuscript, never like UI.
Why a serif-led system The product's output is an academic document. Letting manuscript typography lead the brand makes the interface feel like the artifact it produces — and instantly distinguishes it from every Inter-gray AI tool.
